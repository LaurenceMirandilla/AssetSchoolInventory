Screen blueprints

Six screens assembled out of the components in styleguide.html, using the app's real CSS. These are the target for the existing Razor views — the markup is ordinary Bootstrap plus .sab- classes, so each one is a rewrite of a .cshtml file and nothing else. The reasoning behind each decision is in frontend-design.md.

1 · Dashboard — Asset Officer Home/Index

Opens on what needs a decision, not on what exists. Tiles are the inventory at a glance; the attention list is the actual to-do, with a verb on every row. Today this screen has the tiles and the list but no way to act from it — every row here ends in a button.
